# gomacraft-utility

gomacraft サーバー（ATM10 環境）向けのユーティリティ Mod です。身内サーバーで遊ぶ際の利便性向上と不具合修正に特化しており、新しいブロック・アイテム・ワールドデータなどの追加は行いません。

## 方針

- サーバー・クライアント共通の単一 jar として配布します。通信処理はオプショナルなため、本 Mod を導入していないクライアントからも接続できます。
- 各機能は対象 Mod の有無やバージョン適合性に応じて自動的に有効化され、設定から個別に切り替えられます。対象 Mod がない場合やエラーが発生した場合でも該当機能のみが停止し、ゲームの起動自体は妨げません。
- 起動時に各機能の状態をログへ 1 行で出力します（例: `gomacraft_utility: features ae2_search=on compass=off(mod missing: compass)`）。
- Minecraft および NeoForge のバージョンは gomacraft 本体の構成に合わせます。

## 配布

ビルド済みの jar と sha256 チェックサムはタグごとの GitHub Release に公開し、配布側のマニフェストから参照して取り込みます。
